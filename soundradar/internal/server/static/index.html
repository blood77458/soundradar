    收件箱是空的。

    玩游戏时按一下热键（默认 F8），或点上面的「立即保存」按钮，就会把最近几秒存进来。

    采集端点

    改端点会立刻生效：正在跑的实时打分会话会用新端点重新开始；没有会话在跑就只写进配置文件。

    悬浮窗位置与大小

    X / Y 是「物理像素」（多显示器时可以是负数）。只要 X 或 Y 有一个不是 0，就按绝对坐标摆放；把 X、Y 都设为 0，锚点、显示器和边距才会生效。

    显示行为

    显示 / 隐藏 · 热键 · 状态

    热键编辑

    接受的写法：F1..F24、A..Z、0..9，可选 Ctrl+ / Alt+ / Shift+ / Win+ 前缀（例如 Ctrl+Alt+F9），或者填 none 表示不注册热键。

    回溯保存（P4：刚才那 3 秒）

    关掉后 `overlay` / `serve` / `live` 都不会注册回溯热键（`soundradar recall` 仍然能手动跑一次）。
